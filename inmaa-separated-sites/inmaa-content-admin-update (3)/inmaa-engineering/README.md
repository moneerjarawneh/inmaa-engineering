# منصة إنماء للخدمات الهندسية والمساحية

تطبيق Full‑Stack عربي ومتجاوب لتقدير تكلفة البناء قبل التشطيب وبعده، مع معاينة تفاعلية ثلاثية الأبعاد وحفظ طلبات العملاء.

## ما الذي يعمل فعليًا؟

- الحاسبة ترسل بيانات المشروع إلى الخادم عبر `POST /api/estimate`؛ لا يتم اعتماد السعر من الواجهة.
- الخادم يحسب أثر المساحة، الموقع، مستوى التشطيب، وعدد واجهات الحجر.
- كل تقدير يعرض قيمة مركزية ونطاقًا تقريبيًا ±7.5%.
- المعاينة ثلاثية الأبعاد تتغير مع المساحة والطوابق وواجهات الحجر، وتدعم السحب والتقريب.
- نموذج «اطلب مراجعة مهندس» يعيد احتساب السعر ويحفظ الطلب في `data/quotes.json` مع رقم مرجعي.
- الحقل يدعم إدخال مساحة البناء بالأرقام العربية أو الإنجليزية على الجوال.
- واجهة حساب تشمل الدخول/إنشاء الحساب عبر Google أو رمز SMS، مع خروج آمن عند إعداد مفاتيح الخدمة.
- يدعم الدخول عبر Google وGitHub، مع جلسة آمنة وحجوزات خاصة بكل مستخدم.
- يوجد «مساعد إنماء» اختياري عبر واجهة OpenAI من الخادم؛ لا تُرسل مفاتيح OpenAI للمتصفح.
- التطبيق لا يحتاج إلى أي مكتبات خارجية: Node.js فقط.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm start
```

ثم افتح:

```text
http://localhost:3000
```

## فصل موقع الزوار ولوحة الإدارة

الواجهتان منفصلتان داخل المشروع:

| الموقع | المجلد | متغير النشر |
| --- | --- | --- |
| الزوار | `apps/public-site` | `SITE_ROLE=public` |
| الإدارة | `apps/admin-site` | `SITE_ROLE=admin` |

انشر الخدمة نفسها مرتين مع قاعدة البيانات ومتغيرات الأسرار ذاتها، لكن بدور ومجال مختلفين:

| الخدمة | العنوان المقترح | `APP_ORIGIN` |
| --- | --- | --- |
| موقع الزوار | `https://www.اسم-نطاقك.com` | رابط موقع الزوار |
| لوحة الإدارة | `https://admin.اسم-نطاقك.com` | رابط لوحة الإدارة |

ضع الرابطين أيضًا في `PUBLIC_ORIGIN` و`ADMIN_ORIGIN` في النشرتين. عند استخدام OAuth، سجّل رابطَي العودة لكل من Google وGitHub: `/api/auth/google/callback` و`/api/auth/github/callback` على نطاقي `www` و`admin`.

للتجربة محليًا شغّل `docker compose up --build`، ثم افتح موقع الزوار على `http://localhost:3000` ولوحة الإدارة على `http://localhost:3001`.

للتطوير مع إعادة التشغيل التلقائي:

```bash
npm run dev
```

ولتشغيل الاختبارات:

```bash
npm test
```

## تعديل الأسعار

القيم الافتراضية بالدينار الأردني ويمكن تغييرها بمتغيرات البيئة دون تعديل الواجهة:

| المتغير | القيمة الافتراضية | الوصف |
| --- | ---: | --- |
| `CURRENCY_LABEL` | `د.أ` | اسم العملة المعروض |
| `SHELL_RATE` | `235` | سعر المتر للهيكل قبل التشطيب |
| `ECONOMY_RATE` | `390` | سعر المتر بعد التشطيب الاقتصادي |
| `STANDARD_RATE` | `455` | سعر المتر بعد التشطيب القياسي |
| `PREMIUM_RATE` | `565` | سعر المتر بعد التشطيب الفاخر |
| `STONE_RATE` | `28` | الزيادة لكل متر مربع حجر |
| `PORT` | `3000` | منفذ الخادم |

يمكن نسخ `.env.example` إلى إعدادات منصة الاستضافة، أو تمرير المتغيرات مباشرة إلى عملية Node.

## تفعيل الحساب والمساعد

الواجهة تظهر دائمًا، لكن لا يُفعّل أي مزوّد من دون مفاتيحه:

| الميزة | المتغيرات المطلوبة |
| --- | --- |
| Google / Gmail | `APP_ORIGIN` و`GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET` |
| GitHub | `APP_ORIGIN` و`GITHUB_CLIENT_ID` و`GITHUB_CLIENT_SECRET` |
| التحقق برقم الهاتف | `TWILIO_ACCOUNT_SID` و`TWILIO_AUTH_TOKEN` و`TWILIO_VERIFY_SERVICE_SID` |
| مساعد إنماء | `OPENAI_API_KEY`، ويمكن اختيار `OPENAI_MODEL` |
| قاعدة البيانات والحجوزات | `DATABASE_URL`، ومع الاستضافة المُدارة اترك `DATABASE_SSL` بالقيمة الافتراضية |
| تحديد الموقع | `GOOGLE_MAPS_API_KEY` مقيّد على Geocoding API |
| لوحة الشقق والصور | `ADMIN_EMAILS` و`CLOUDINARY_CLOUD_NAME` و`CLOUDINARY_API_KEY` و`CLOUDINARY_API_SECRET` |

أضف رابط العودة `https://اسم-نطاقك/api/auth/google/callback` في إعدادات عميل OAuth لدى Google. لا تضف مفاتيح Google أو Twilio أو OpenAI إلى ملفات الواجهة أو إلى Git.

### إعداد Google OAuth

1. افتح Google Cloud Console وأنشئ مشروعًا جديدًا.
2. من **APIs & Services → OAuth consent screen** أضف اسم الموقع وبريد الدعم والنطاق المنشور.
3. من **Credentials → Create credentials → OAuth client ID** اختر **Web application**.
4. أضف `https://اسم-نطاقك/api/auth/google/callback` ضمن **Authorized redirect URIs**، ثم ضع Client ID وClient Secret في متغيرات الاستضافة.

### إعداد GitHub OAuth

1. من GitHub افتح **Settings → Developer settings → OAuth Apps → New OAuth App**.
2. أدخل رابط الموقع في Homepage URL، وأدخل `https://اسم-نطاقك/api/auth/github/callback` في Authorization callback URL.
3. أنشئ التطبيق وانسخ Client ID، ثم أنشئ Client Secret وضعهما في متغيرات الاستضافة فقط.

## PostgreSQL والحجوزات

بعد إضافة `DATABASE_URL` وتشغيل `npm install` ينشئ الخادم جداول المستخدمين والجلسات والحجوزات تلقائيًا عند أول عملية دخول. لا يستطيع مستخدم غير مسجّل إنشاء حجز أو قراءة حجوزات، كما لا تعرض الواجهة إلا الحجوزات المرتبطة بالجلسة الحالية.

## إدارة الشقق

توجد لوحة جديدة على `/admin.html`. أضف بريد حساب الإدارة إلى `ADMIN_EMAILS`، ثم سجّل الدخول عبر Google أو GitHub بالحساب نفسه. تتيح اللوحة إضافة وتعديل وحذف الشقق، وربطها بمنطقة، واختيار أحد أنواع التشطيب الثلاثة فقط: `Super` و`Super Deluxe` و`VIP`، وحفظ حتى 12 صورة لكل شقة.

استخدم Cloudinary للصور: أنشئ Product Environment، ثم ضع Cloud name وAPI key وAPI secret في متغيرات الاستضافة. الواجهة لا ترى API secret؛ الخادم وحده ينشئ توقيع الرفع بعد التحقق من صلاحية الأدمن.

### ترحيل البيانات القديمة

خذ نسخة احتياطية أولًا. تُحفظ التشطيبات الجديدة كـ `super` و`super_deluxe` و`vip`. عند وجود جدول شقق قديم، حوّل القيم عبر جدول قرار قبل النشر، مثل: `اقتصادي` أو `قياسي` → `super`، `فاخر` → `super_deluxe`، وقيّم أي قيمة مميزة يدويًا قبل تحويلها إلى `vip`. لا تحذف العمود القديم إلا بعد مراجعة تقرير عدد السجلات في كل قيمة.

يوجد مثال ترحيل محافظ في `migrations/002_finish_type_migration.sql`: يحتفظ بالقيمة السابقة في `legacy_finish_type` ويطبع تقرير تدقيق قبل تثبيت قيد القيم الجديدة. راجع التقرير وعدّل الخرائط غير المناسبة لبياناتك قبل تشغيله على الإنتاج.

تستخدم الواجهة Pagination مبنية على cursor، وفهارس مركبة للمنطقة والتشطيب والسعر، وفهرس منفصل للترتيب الزمني. عند نمو الزيارات أكثر، أضف Redis لتخزين نتائج البحث الشائعة واقتراحات المناطق مع مدة قصيرة، واحتفظ بـ PostgreSQL كمصدر البيانات الأساسي.

## HTTPS وتحديد الموقع

انشر التطبيق على منصة تدعم HTTPS تلقائيًا مثل Render أو Railway، واجعل `APP_ORIGIN` هو رابط `https://` النهائي. يعمل زر «تحديد موقعي الحالي» فقط في سياق آمن (HTTPS أو localhost)، ويستدعي `navigator.geolocation.getCurrentPosition` ثم يرسل الإحداثيات إلى الخادم للترميز الجغرافي العكسي عبر Google Maps. يمنع الموقع التضمين داخل iframe ويعلن `Permissions-Policy: geolocation=(self)`؛ لذلك لا يحتاج أي إعداد iframe إضافي.

## ملاحظات أمان

- لا يوجد دخول بكلمة مرور محلية حاليًا، لذا لا توجد كلمات مرور لتشفيرها؛ المصادقة عبر OAuth/SMS فقط.
- الأسرار محصورة في متغيرات البيئة و`.env` وملفات البيانات المحلية مستثناة من Git.
- تستخدم الاستعلامات في PostgreSQL معاملات ممرّرة (`$1`, `$2`…) بدل بناء SQL من مدخلات المستخدم.
- الجلسة مخزّنة كمعرّف عشوائي HttpOnly/Secure/SameSite=Strict في Cookie، وصلاحيتها 14 يومًا.
- الطلبات الحساسة محمية برمز CSRF، والحجوزات وOTP والمساعد محددة المعدل، وتسجّل محاولات الرفض أو الإفراط دون كشف تفاصيل للمستخدم.
- يضيف الخادم CSP وX-Frame-Options وX-Content-Type-Options وPermissions-Policy وHSTS عند تشغيل رابط HTTPS.

لا يوفر OpenAI مزوّد دخول عام باسم «تسجيل الدخول بحساب ChatGPT» لمواقع الويب العادية؛ لذلك تم ربط ChatGPT كمساعد داخل الموقع، بينما يبقى الدخول الحقيقي عبر Google أو الهاتف.

## منطق التقدير

مساحة الإدخال هي إجمالي المساحة المبنية في جميع الطوابق. يحسب الخادم:

1. سعر الهيكل = المساحة × سعر الهيكل × معامل الموقع.
2. سعر البناء المشطب = المساحة × سعر مستوى التشطيب × معامل الموقع.
3. يقدّر مساحة واجهات الحجر من بصمة المبنى وعدد الطوابق، ثم يضيف كلفة الحجر إلى سعر التشطيب فقط.

التقدير لا يشمل الأرض والرسوم الحكومية وأعمال التربة والاستنادات والخدمات الخارجية؛ ويجب تأكيده بعد مراجعة المخططات والموقع.

## نقاط الـ API

- `GET /api/health` — فحص حالة الخدمة.
- `GET /api/config` — الأسعار والمواقع المسموحة للواجهة.
- `POST /api/estimate` — حساب تقدير موثوق من الخادم.
- `POST /api/quotes` — حفظ طلب عميل بعد التحقق وإعادة الحساب.
